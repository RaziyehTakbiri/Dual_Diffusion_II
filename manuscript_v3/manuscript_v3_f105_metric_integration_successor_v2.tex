For domain $d\in\{\mathrm{R3\mbox{-}PHYS},\mathrm{R4\mbox{-}RETAIL}\}$, let
$J_d(e)\in\mathbb R^{D_d}$ be the injective domain event map, where
$D_{\mathrm{PHYS}}=112$ and $D_{\mathrm{RETAIL}}=10$. Define
\[
k_{E,d}(e,e')=\exp\!\left(-\frac{\lVert J_d(e)-J_d(e')\rVert_2^2}{2}\right).
\]
For an occurrence-expanded configuration $x$, write $n_x=x(E_d)$ and
\[
m_d(x)=
\begin{cases}
0,&n_x=0,\\
n_x^{-1}\sum_{e\in x}k_{E,d}(e,\cdot),&n_x>0,
\end{cases}
\qquad \Phi_d(x)=(n_x,m_d(x)).
\]
All four squared parameters satisfy
$a_d^2=b_d^2=\tau_d^2=\sigma_d^2=1$, so
\[
k_{\Gamma,d}(x,x')=\exp\!\left[-\frac12\left\{
(n_x-n_{x'})^2+\lVert m_d(x)-m_d(x')\rVert_{\mathcal H_d}^2
\right\}\right].
\]
For $2\le R\le128$ independent conditional draws,
\[
\widehat{\operatorname{CKS}}_d
=\frac{1}{R(R-1)}\sum_{r\ne r'}k_{\Gamma,d}(X_r,X_{r'})
-\frac{2}{R}\sum_{r=1}^{R}k_{\Gamma,d}(X_r,x).
\]
This is lower-is-better. The paired effect is direct minus guide, so a
positive value favors the guide. Cross-domain evaluation is forbidden.
